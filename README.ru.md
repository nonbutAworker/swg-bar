**Узнайте, проверяется ли ваш HTTPS-трафик. Обход SWG — в один клик.**

[Официальный сайт](https://swgbar.com/ru/) · [Скачать для Mac](https://swgbar.com/ru/#pricing) · [Руководства](https://swgbar.com/ru/guides/) · [CLI](https://swgbar.com/ru/cli/) · [MCP](https://swgbar.com/ru/mcp/)

SWG bar — нативное приложение для строки меню macOS, позволяющее обнаруживать **проверку HTTPS/SSL (break-and-inspect)** корпоративными защищёнными веб-шлюзами (SWG) — такими как Zscaler, Netskope и Cloudflare Gateway — и управлять **подоменным обходом SWG в один клик**. Изучайте результаты проверки доменов и данные сертификатов на Mac, просматривайте сохранённые локальные результаты в расширении Chrome или управляйте проверками и правилами из Терминала и ИИ-агентов разработки.

## Возможности

- **Проверка HTTPS/SSL и анализ сертификатов:** выявляйте проверяемые домены, просматривайте издателей, сроки действия, отпечатки SHA-256 и связанные имена хостов, а также сравнивайте оценку доверия Связки ключей macOS (включая корневые CA, установленные через MDM) с независимой проверкой по публичным корневым центрам.
- **Подоменный обход SWG в один клик:** направляйте выбранные имена хостов в macOS без расшифровки HTTPS на шлюзе в авторизованных сетях — через строку меню, CLI или MCP.
- **Расширение Chrome (`2.1.13`):** просматривайте на панели инструментов браузера локальный результат для текущего домена, сохранённый приложением Mac.
- **Нативный CLI `swgbar` и сервер MCP:** запрашивайте статистику инспекции, запускайте TLS-проверки по запросу и переключайте обход по доменам из Терминала ([руководство по CLI](https://swgbar.com/ru/cli/)) или ИИ-клиентов с поддержкой MCP, таких как Claude Desktop, Cursor, Windsurf и Claude Code ([руководство по MCP](https://swgbar.com/ru/mcp/)).

Данные обнаружения анализируются и хранятся локально на Mac. Проверки открывают отдельные исходящие IPv4 TLS-соединения; расширение Chrome работает только на чтение через Chrome Native Messaging и показывает имеющиеся локальные результаты. Подробнее: [как это работает](https://swgbar.com/ru/how-it-works/), [конфиденциальность](https://swgbar.com/ru/privacy/) и [конфиденциальность расширения](https://swgbar.com/ru/extension-privacy/).

## Начало работы

Требуются **macOS 14 или новее и Mac с Apple silicon** (`arm64`). Бесплатный пробный период включает **14 дней фактического использования** без привязки карты; актуальные личные и командные тарифы указаны на [официальном сайте](https://swgbar.com/ru/#pricing).

1. Скачайте подписанный и нотаризованный установщик `.pkg` (`2.4.12`, сборка `42`) с [официального сайта](https://swgbar.com/ru/#pricing) и следуйте [инструкции по установке](https://swgbar.com/ru/install/).
2. Откройте SWG bar из строки меню, чтобы проверить имена хостов, корневые CA и настройки подоменного обхода SWG.
3. При необходимости подключите [расширение Chrome](https://swgbar.com/ru/chrome-extension/), настройте [CLI `swgbar`](https://swgbar.com/ru/cli/) или добавьте [сервер MCP](https://swgbar.com/ru/mcp/) в свой ИИ-клиент.

Приложение для Mac `2.4.12` и входящее в комплект расширение Chrome `2.1.13` поддерживают все 12 языков сайта. Обновления в Интернет-магазине Chrome публикуются отдельно после модерации; сверяйте версию, указанную в магазине.

## Руководства: проверка HTTPS, обход SWG и ошибки TLS в CLI и ИИ

При диагностике на macOS разделяйте **маршрутизацию трафика** и **расшифровку TLS**. Обход SWG меняет маршрут соединения для выбранного хоста в обход расшифровки на шлюзе; исключение из TLS-инспекции может оставить трафик проходящим через шлюз без расшифровки, поэтому публичная цепочка сертификатов сама по себе не доказывает смену маршрута.

- [Как обнаружить проверку HTTPS и SSL на Mac](https://swgbar.com/ru/guides/detect-https-inspection/) — проверка цепочек сертификатов и локальных корневых CA в macOS.
- [Корпоративный SWG и MDM: проверка HTTPS на Mac](https://swgbar.com/ru/guides/enterprise-swg-https-inspection-macos/) — почему при работе Zscaler, Netskope и Cloudflare Gateway значок замка в браузере сохраняется благодаря корневым CA из MDM.
- [Как обойти SWG на Mac](https://swgbar.com/ru/guides/how-to-bypass-swg/) — пошаговая настройка по доменам, разрешение сетевого расширения macOS, поведение при перезапуске и сетевые ограничения.
- [Обход SWG и исключение TLS-инспекции (break-and-inspect)](https://swgbar.com/ru/guides/swg-bypass-vs-tls-exception/) — различия между подоменной маршрутизацией и исключениями расшифровки на шлюзе.
- [Как исправить ошибки сертификатов TLS и SSL из-за SWG в CLI и ИИ на Mac](https://swgbar.com/ru/guides/swg-tls-certificate-errors-macos/) — устранение `CERTIFICATE_VERIFY_FAILED` и ошибок локального издателя в `git`, `npm`, `Python`, `Claude Code` и `Cursor`.

**Статус выпуска, проверено 18 ноября 2026 года:** актуальная опубликованная версия — **SWG bar 2.4.12** (сборка `42`), включающая подписанное нативное сетевое расширение для подоменного обхода SWG, CLI `swgbar` с сервером MCP и расширение Chrome `2.1.13`. Контрольная сумма SHA-256, подпись Apple и нотарификация пакета проверены. См. [информацию о выпусках](https://swgbar.com/ru/releases/) и [официальные руководства](https://swgbar.com/ru/guides/).
